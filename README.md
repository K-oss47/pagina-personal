# Página web personal

Tarea 1: página web personal hecha con HTML y CSS.

**Autor:** Kelvin Mercedes
**Institución:** Instituto Tecnológico de las Américas (ITLA)

## Descripción

Página personal de una sola pantalla con diseño oscuro, degradados y tarjetas. Incluye mi foto, mis datos de contacto, mis hobbies, el enlace a mi red social y un video de YouTube que me gusta.

## Elementos incluidos

| Requisito | Dónde está |
|---|---|
| Foto | Portada, dentro de un círculo con borde de degradado |
| Nombre y apellido | Portada y sección "Datos de contacto" |
| Teléfono | Sección "Datos de contacto" (enlace `tel:`) |
| Dirección | Sección "Datos de contacto" |
| Correo electrónico | Sección "Datos de contacto" (enlace `mailto:`) |
| Hobbies | Sección "Hobbies", mostrados como etiquetas |
| Redes sociales | Sección "Mis redes sociales" (Instagram) |
| Video de YouTube | Sección "Un video de mi agrado" (miniatura con enlace al video) |

## Tecnologías

- HTML5
- CSS3 (variables, flexbox, grid, degradados, diseño adaptable a celular)

## Estructura del proyecto

```
pagina-personal/
├── index.html      # Estructura y contenido de la página
├── estilos.css     # Estilos y diseño
├── foto.png        # Mi foto
└── README.md       # Este archivo
```

## Cómo ejecutarlo

1. Descarga o clona la carpeta `pagina-personal`.
2. Ábrela en Visual Studio Code.
3. Haz clic derecho en `index.html` y elige **Open with Live Server** (extensión Live Server), o abre `index.html` directamente en el navegador.
